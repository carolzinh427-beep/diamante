# Diamante Presentes - Landing Page Oficial 💎

Landing page moderna, responsiva (mobile-first) e de alta conversão para a loja **Diamante Presentes** (Presentes e Importados em Brasília - DF).

## 🚀 Tecnologias
- **HTML5, CSS3 e JavaScript puro** (Sem frameworks pesados)
- **Google Fonts (Montserrat)**
- **Ícones SVG vetorizados**
- **Mobile-first** otimizado para alta velocidade e baixo consumo de dados
